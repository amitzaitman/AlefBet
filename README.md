# AlefBet — משחקי קריאה וחשבון לילדים

פלטפורמת משחקים ללימוד קריאה לילדים בגילאי 3–8: הכרת האותיות, התנועות
והניקוד — עם שמע עברי שעובד **גם ללא אינטרנט**, ופידבק בונה בלבד (בלי
"טעית!", עם רמזים מדורגים במקום).

**🌐 לשחק אונליין:** [amitzaitman.github.io/AlefBet](https://amitzaitman.github.io/AlefBet/)

---

## הפעלה מקומית

**Windows:** לחיצה כפולה על `start.bat` — השרת עולה והדפדפן נפתח לבד.

**מכל טרמינל:**

```bash
node start.js        # http://localhost:8080
node start.js 3000   # פורט אחר
```

> דרוש [Node.js](https://nodejs.org) גרסה 20 ומעלה. אין תלויות נוספות להרצה.

## המשחקים

| משחק | מה מתרגלים | איך |
|---|---|---|
| 🟩 **מזהים שברים** (`fraction-picture`) | חצאים, שלישים ורבעים | מזהים כמה חלקים שווים צבועים |
| 🧩 **משלימים לשלם** (`fraction-whole`) | השלמת שברים | בוחרים את השבר שחסר לשלם |
| ⚖️ **משווים שברים** (`fraction-compare`) | גודל ושוויון שברים | משווים המחשות של שלמים באותו גודל |
| 🦁 **התאמת אותיות** (`letter-match-animals`) | זיהוי אותיות | מחברים כל אות לחיה שמתחילה בה |
| אָ **לימוד ניקוד** (`nikud-match`) | סימני הניקוד | גוררים את האות אל צורת הניקוד הנכונה |
| 🔊 **קריאת הברות** (`syllable-read`) | חיבור אות+תנועה | שומעים הברה ובוחרים את הכרטיס הנכון |
| 🎤 **אמור את הניקוד** (`nikud-speak`) | הגיית תנועות | אומרים את התנועה למיקרופון — זיהוי פורמנטים מקומי |
| 🎙️ **אולפן הצלילים** (`sound-studio`) | *כלי למורה/הורה* | מקליטים את האותיות, הניקוד וההברות לבנק צלילים מקומי |

עקרונות משותפים לכל המשחקים:

- **פידבק בונה בלבד** — טעות לא מסומנת באדום ולא משמיעה צליל שלילי.
  אחרי כמה ניסיונות מגיע רמז עדין (התשובה מהבהבת), ואז עזרה מוגברת
  (המסיחים מתעמעמים). ראו `core/hints.js`.
- **RTL מלא, ניקוד מלא, כפתורים גדולים** (64px+) לגיל הרך.
- **יציבות** — שום פעולת שמע לא חוסמת את המשחק; הבטחות שמע תמיד נפתרות.

## שמע עברי ללא רשת — איך זה עובד

בזמן משחק **לא יוצאת אף בקשת רשת**. כל השמעה עוברת שרשרת ספקים מקומיים
(`audio/hebrew-audio.js`):

1. **בנק הצלילים** — הקלטות אנושיות ב-IndexedDB במכשיר. ממלאים אותו
   באחת משתי דרכים באולפן הצלילים:
   - 🎤 הקלטה בקול שלכם (מורה/הורה) — הכי טוב פדגוגית.
   - ⬇️ **מילוי אוטומטי חד-פעמי** — הורדת קולות מחשב דרך ה-proxy של
     הפרויקט (חיבור רשת פעם אחת, ואז הכול מקומי לתמיד).
2. **קול מערכת** — Web Speech API מקומי (`audio/tts.js`), עם watchdog
   נגד קולות רשת תקועים והעדפת קול מותקן כשאין אינטרנט.
3. **סינתזת פונמות** — יצירת תנועות והברות ב-Web Audio
   (`audio/phoneme-synth.js`), ההיפוך של גלאי הפורמנטים. זמינה תמיד.

אם שום ספק לא הצליח — מוצג באנר ברור לילד; אין כשלים שקטים.

גם הניקוד האוטומטי (Dicta Nakdan, `utils/nakdan.js`) לא נדרש בזמן משחק:
טקסטים מנוקדים מראש מדלגים על הרשת לגמרי, ותוצאות שהושגו פעם אחת נשמרות
ב-localStorage. הגופנים (Rubik, Frank Ruhl Libre) ארוזים בריפו — אין תלות
ב-Google Fonts.

## פיתוח

התקנה ראשונית (וגם אחרי עדכון גרסת Playwright):

```bash
npm ci
npm run setup:browsers
```

לפני דחיפה מריצים פקודה אחת:

```bash
npm run verify
```

היא מריצה lint, בדיקת טיפוסים, בדיקות יחידה, בנייה נקייה וכל בדיקות הדפדפן,
כולל אופליין ב-WebKit. כשל עוצר את התהליך.
הבנייה מוחקת תוצרים ישנים ומעדכנת את `framework/dist/`; יש לכלול אותו ב-commit.
CI והפריסה משתמשים באותו תהליך, ובודקים גם שהתוצרים תואמים ל-commit.

CI אוטומטי רץ על PR בלבד; ענף בלי PR אפשר לבדוק ידנית דרך Actions → CI →
Run workflow. כך push לענף עם PR אינו מפעיל חבילה שנייה. דחיפה למיין מריצה
את כל הבדיקות לפני הפרסום. שינוי שמכיל רק Markdown, קבצים תחת `docs/` או
`LICENSE` אינו מפעיל CI או פרסום. שינוי מעורב בתיעוד ובקוד כן מפעיל אותם.

שלוש החזרות הנוספות של בדיקת עדכון אופליין רצות בשינויי אופליין/בנייה/תלויות/CI,
בהרצה ידנית, ובימי שני ב-03:17 UTC. רשימת הנתיבים נמצאת ב-`scripts/ci-scope.js`.
בדיקת האופליין הרגילה נשארת בכל אימות. אפשר להריץ את החזרות מקומית עם
`npm run test:stability` אחרי בנייה או `verify`.

בזמן פיתוח אפשר לקצר:

| צורך | פקודה |
|---|---|
| בדיקות מהירות ללא דפדפן | `npm run check` |
| בדיקת משחק מסוים, כולל בנייה טרייה | `npm run e2e -- e2e/math.spec.js` |
| בנייה בלבד | `npm run build` |

תוצאות ו-traces נשמרים תחת `test-results/games/` ו-`test-results/stability/`.
ב-CI הם מצורפים אוטומטית אם בדיקה נכשלת.

**גבולות השיתוף:** לוגיקה ייחודית נשארת במשחק; רכיב משותף מחלצים כשכמה
משחקים צריכים אותה התנהגות. `runGame` הוא עזר אופציונלי למשחקי סיבובים.
הוא מטפל בניקוד, מעבר וסיום; המשחק מגדיר רינדור, תשובות ורמזים.
`createChoiceRound` מחבר כרטיסי בחירה לנעילת התשובות של הסיבוב.
`scope.use` רושם רכיבים לניקוי, `scope.listen` מאזינים ו־`scope.schedule` טיימרים;
כולם מתנקים אוטומטית במעבר, בהתחלה מחדש וביציאה. להשמעת הברות מעבירים
`{ signal: scope.signal }`. החזרת פונקציית ניקוי עדיין נתמכת. משחק הדיבור והאולפן שומרים על הזרימה הייעודית שלהם.

המשחקים טוענים `framework/dist/runtime.js` ו-`runtime.css`. העורך וה-CSS שלו
נטענים רק בלחיצה על **ערוך** או **קול**, ונשמרים במטמון לשימוש חוזר ללא רשת.
פתיחת העורך לראשונה דורשת חיבור, אך המשחק עצמו והתוכן השמור אינם תלויים בו.
חבילת `alefbet.js` הישנה נשארת לתאימות. אחרי שינוי בתשתית מריצים `npm run build`.

### מבנה הפרויקט

```
framework/src/
  core/      GameShell, GameState, round-manager, hints, bootstrap/runGame, content storage
  audio/     hebrew-audio (שרשרת ההשמעה), tts, phoneme-synth,
             sound-bank-compiler, audio-context (שחרור iOS),
             voice-recorder, voice-store, vowel-detector, sounds
  data/      hebrew-letters, nikud
  ui/        option-cards, progress-bar, feedback, zones, nikud-box,
             audio-status-banner, completion-screen, ...
  utils/     nakdan (ניקוד אוטומטי, עם מטמון מתמיד)
  runtime/   API לרכיבי המשחק
  editor/    עורך משחקים בדפדפן (TypeScript + zod), נטען לפי בקשה
  styles/    alefbet.css + גופנים מקומיים
framework/dist/   תוצר בנוי ומחויב — המשחקים טוענים ממנו ישירות
games/<name>/     index.html + game.js + game.css למשחק
e2e/              בדיקות Playwright
deploy/           Cloudflare Worker: proxy לנקדן + מסלול /tts לקימפול
```

### משחק חדש

```bash
npm run new:game -- my-game "שם המשחק"
node start.js
```

הפקודה יוצרת `games/my-game/` מתבנית עובדת ורושמת אותו בקטלוג. פותחים
`http://localhost:8080/games/my-game/` ועורכים את `game.js` ואת `game.css`.
מזהה כפול או לא תקין נדחה בלי לדרוס קבצים. הקטלוג קובע גם את קובצי האופליין.
אפשר להשתמש באימוג׳י בשדה `icon` בלי לערוך את דף הבית.

- **משחק כללי:** מייבאים מ-`framework/dist/common.js`; הסגנון המשותף נשאר `runtime.css`.
- **יכולות עברית:** מייבאים לפי צורך מ-`runtime.js`, שממשיך לייצא גם את ה-API הקיים.
- `preloadTexts` אופציונלי. נקדן נטען רק כאשר מבקשים לנקד רשימת טקסטים לא ריקה.
- **בחירת תשובה:** `runGame` + `createChoiceRound`; ראו `games/make-ten/game.js`.
- **אינטראקציה מותאמת:** `runGame` + רכיבים ומצב מקומי; ראו `games/number-line/game.js`.
- **פעילות ללא סיבובים:** `bootstrapGame` + `createRoundScope`; ראו [מדריך הפיתוח](docs/adding-games.md).

בדיקה לפני דחיפה: `npm run verify`.
יש לחייב גם את `framework/dist/` המתחדש. אין צורך לערוך את ליבת התשתית
בשביל תוכן, רמזים או חוקי משחק חדשים.

## פריסה

דחיפה ל-`main` מפרסמת אוטומטית ל-GitHub Pages
(`.github/workflows/deploy.yml`).

**Proxy (חד-פעמי, אופציונלי):** ה-worker שב-`deploy/cloudflare-nakdan-proxy/`
משרת שני מסלולים עם CORS — ניקוד אוטומטי (Dicta) ומסלול `/tts` למילוי
האוטומטי של בנק הצלילים. פריסה עם `wrangler deploy`; חיבור דרך
`?nakdanProxy=...` או `localStorage`. פרטים ב-README של התיקייה.

### תוכן שמור ועדכוני אופליין

משחק עם עורך יכול להעביר `editor.content` עם `createRound`, `validateRound`,
`version` (ברירת מחדל 1) ו-`migrate` אופציונלי. ה-runtime בודק תוכן שמור לפני
הפעלתו. מיגרציה מקבלת את המסמך הישן ומחזירה מסמך בגרסה הנוכחית, באותו מזהה משחק.
תוכן לא תקין או גרסה לא נתמכת נשארים באחסון; המשחק משתמש בתוכן ברירת המחדל.
הוולידציה אינה טוענת את העורך או את zod. כללי המשחק נשארים בתיקיית המשחק.

שגיאת שמירה מוצגת בעורך, עם אפשרות לייצא עותק ולנסות שוב. חזרה למשחק שומרת
שינויים תחילה ונשארת בעורך אם השמירה נכשלה.

אחרי שינוי בקוד האתר או בנכסים מריצים `npm run build` ומחייבים את `framework/dist`.
הבנייה מייצרת מזהה אופליין דטרמיניסטי. גרסה חדשה מתקינה את כל קובצי הליבה לפני
הפעלה, וממתינה לסגירת הלשוניות הישנות. קובצי עורך נטענים רק לפי דרישה ונבדקים
מול אותה גרסה. עדכון שנקטע משאיר את הגרסה הקודמת זמינה.

`npm run verify` כולל בדיקות מגע ו-WebKit. חזרות יציבות נוספות מופעלות לפי סוג השינוי ובתזמון השבועי.
`npm run setup:browsers` מתקין את הדפדפנים הדרושים. אותן בדיקות נדרשות לפני פריסה.
בדיקת שמע ואופליין בטלפון אמיתי עדיין נדרשת לאחר מיזוג.
