# AlefBet: משחקי קריאה וחשבון לילדים

משחקים קצרים בעברית לגילאי 3 עד 8: אותיות, ניקוד והברות, וחשבון שמתחיל
מסיפור. אחרי ביקור אחד האתר עובד גם בלי אינטרנט, והשמע העברי מושמע מהמכשיר
עצמו. אין במשחקים "טעית": טעות מביאה רמז, לא סימן אדום.

**לשחק:** [amitzaitman.github.io/AlefBet](https://amitzaitman.github.io/AlefBet/)

## המשחקים

| תחום | משחק | מה מתרגלים |
|---|---|---|
| קריאה | התאמת אותיות (`letter-match-animals`) | בוחרים מילה שמתחילה באות |
| קריאה | לימוד ניקוד (`nikud-match`) | גוררים אות אל הניקוד המתאים, או בוחרים בלחיצה |
| קריאה | קריאת הברות (`syllable-read`) | שומעים הברה ובוחרים אות וניקוד |
| קריאה | אמור את הניקוד (`nikud-speak`) | אומרים תנועה למיקרופון; הזיהוי נעשה במכשיר |
| חשבון | תפוחים בסל (`apple-basket`) | סופרים בנגיעה ושמים בסל בדיוק כמה שצריך, עד 10, לגיל 3 עד 5 |
| חשבון | סיפורי בלונים (`balloon-stories`) | סיפור קצר קורה על המסך, ובו חיבור וחיסור עד 10 |
| חשבון | משלימים לעשר (`make-ten`) | סופרים משבצות ובוחרים כמה חסר עד עשר |
| חשבון | מחלקים בשווה (`fair-share`) | מחלקים עוגיות בעצמם: כמה לכל אחד, חצי, שליש ורבע, וכמה צלחות מתמלאות |
| חשבון | קפיצות על ציר המספרים (`number-line`) | חיבור וחיסור עד 10 בתנועה על הציר |
| חשבון | מפרקים תרגיל ארוך (`long-exercise`) | פותרים תרגיל עד 20 חלק אחר חלק |
| חשבון | צובעים שברים (`fraction-picture`) | צובעים חלקים כדי לבנות שבר |
| חשבון | משלימים לשלם (`fraction-whole`) | מוסיפים את החלקים החסרים עד השלם |
| חשבון | משווים שברים (`fraction-compare`) | חצאים, שלישים ורבעים |
| למבוגרים | אולפן הצלילים (`sound-studio`) | מקליטים אותיות, ניקוד והברות, והמשחקים משמיעים את ההקלטות |

כל משחק יושב בתיקייה משלו תחת `games/`. הרשימה שבדף הבית נקראת מ-`games/catalog.js`.

## הפעלה במחשב

ב-Windows: לחיצה כפולה על `start.bat`. בכל מחשב אחר:

```bash
node start.js        # http://localhost:8080
node start.js 3000   # פורט אחר
```

צריך [Node.js](https://nodejs.org) גרסה 20 ומעלה. כדי לשחק אין צורך להתקין דבר.

## פיתוח

```bash
npm ci
npm run setup:browsers   # פעם אחת, ושוב אחרי עדכון של Playwright
npm run check            # מהיר: lint, בדיקת טיפוסים ובדיקות יחידה
npm run verify           # הכול, כולל בנייה ובדיקות דפדפן; חובה לפני דחיפה
npm run new:game -- my-game "שם המשחק"
```

אחרי שינוי בקוד האתר מריצים `npm run build` ומחייבים גם את `framework/dist/`.
המשחקים טוענים ממנו ישירות, ולכן אין צעד בנייה בהפעלה.

דחיפה ל-`main` מפרסמת ל-GitHub Pages, ורק אחרי שכל הבדיקות עברו. אחרי פרסום
בודקים בטלפון אמיתי, בלי רשת, משחק אחד מתחילתו ועד סופו, עם קול.
